# 📖 TỪ ĐIỂN THUẬT NGỮ — GLOSSARY (vi ↔ en)

> Chuẩn thuật ngữ dùng thống nhất trong toàn hệ thống: giao diện, file lang, email, thông báo, tài liệu.
> Quy tắc: **tiếng Việt có dấu đầy đủ**, viết hoa đầu câu, không lẫn tiếng Anh trừ tên riêng/thương hiệu.
